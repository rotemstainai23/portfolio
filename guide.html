היסטוריה

פתיחת המערכת

הפעלה ראשונה בארבעה שלבים

הרצת השרת המקומי מאפשרת שליטה מלאה עם מחירים חיים ויכולת הפעלת ניתוחים.

1

פתח טרמינל בתיקיית הפרויקט

תיקיית הפרויקט נמצאת בנתיב:

C:\Users\רותם\portfolio\
ב-Windows Explorer: לחץ על שורת הכתובת, הקלד cmd, Enter.
2

הפעל את השרת

הפקודה מריצה את Flask על פורט 5000:

python app.py
השרת מוכן כשרואים: Running on http://127.0.0.1:5000
3

פתח דפדפן

נווט לכתובת המקומית:

מקומי http://127.0.0.1:5000
אל תשתמש ב-localhost, תמיד 127.0.0.1.
4

הדשבורד נטען

הדשבורד הראשי (Hub) מציג: באנר ירוק "מצב חי", ערך התיק הכולל, רשת חלוניות לניווט, ולוח סטטוס עבודות. לחץ על כל חלונית לכניסה לדוח המתאים.

1

בחר טיקר בדשבורד הראשי

לחץ על כרטיס הטיקר ב-Hub, או נווט ישירות לעמוד האורקל של המניה.

2

לחץ "הרץ שרשרת מלאה"

הכפתור שולח בקשה ל-POST /api/run. אם הניתוח עדכני (פחות מ-14 ימים) מופיעה הודעה עם אפשרות לעקוף.

משך ריצה: 3-7 דקות. הדף מתעדכן בזמן אמת.
3

עקוב אחרי הסטטוס

progress bar מציג את שלב הסוכן הנוכחי. בסיום מופיע verdict צבעוני ועמוד התוצאות נטען.

4

קרא את הפלט

כל סוכן מספק נקודת מבט שונה. ה-IC מסכם עם verdict סופי: STRONG BUY / BUY / HOLD / SELL. ציון 1-10 מצורף לכל החלטה.

אוטומציה

מה רץ אוטומטית?

GitHub Actions מריץ עבודות בענן (ב-Ubuntu) גם כשה-PC כבוי, ודוחף את התוצאות ל-repo.

עבודה מתי איפה פלט
דוח יומי ימים א-ה, 17:00 ענן daily_latest.json
שבועי (CEO) שבת, 09:00 ענן ceo_weekly.json
סקנר מניות ראשון, 10:00 ענן scanner-results.json
אינדקס reviews יחד עם הדוח היומי ענן _reviews_index.json
בריאות תיק ידני ידני POST /api/portfolio/health
שרשרת AI לטיקר לפי דרישה ידני analyses/TICKER/_reviews/
לוח הסטטוס בדשבורד הראשי מציג מתי כל עבודה רצה לאחרונה ואיזו מהן זקוקה לרענון.
התקנה על הטלפון

PWA — אפליקציה על מסך הבית

המערכת היא Progressive Web App מלאה. ניתן להתקין אותה על הטלפון כאפליקציה עצמאית שעובדת גם ללא חיבור.

כתובת הענן (לשמור):

HTTPS https://rotemstainai23.github.io/portfolio/
דרישה מוקדמת: לפני שמתקינים, יש להפעיל את GitHub Pages בהגדרות ה-repo:
Settings ‹ Pages ‹ Source: Deploy from branch ‹ main / (root) ‹ Save

Android (Chrome)

  1. פתח Chrome בטלפון
  2. נווט לכתובת הענן למעלה
  3. הקש על שלוש הנקודות (פינה ימנית עליונה)
  4. בחר "הוסף למסך הבית"
  5. אשר את שם האפליקציה ולחץ "הוסף"
  6. האייקון יופיע על מסך הבית

iPhone / iPad (Safari)

  1. פתח Safari דווקא (לא Chrome)
  2. נווט לכתובת הענן למעלה
  3. הקש על כפתור השיתוף (ריבוע עם חץ למעלה) בתחתית
  4. גלול ובחר "הוסף למסך הבית"
  5. הקש "הוסף" בפינה ימנית עליונה
  6. האייקון יופיע על מסך הבית
ב-iOS, PWA עובד רק דרך Safari. Chrome ב-iPhone לא תומך ב"הוסף למסך הבית" עם יכולות offline.
לאחר ההתקנה

פתח את האפליקציה ממסך הבית

האפליקציה נפתחת במצב standalone (ללא כרום/ספארי) עם RTL מלא, כמו אפליקציה נייטיב.

מצב ללא רשת (Offline)

לאחר ביקור ראשון, Service Worker שומר את הדשבורד בזיכרון המכשיר. כנס למצב טיסה ורענן, הנתונים האחרונים יוצגו.

עדכונים אוטומטיים

GitHub Actions מריץ את הדוח היומי כל יום ב-17:00. בפתיחת האפליקציה תראה תמיד את הנתונים הכי עדכניים שנדחפו לענן.

שאלות נפוצות

שאלות ותשובות

הדשבורד מציג "ענן" גם כשהשרת רץ, למה?
הדשבורד שולח ping ל-/api/ping עם timeout של 2.5 שניות. אם השרת לקח יותר זמן לעלות, הוא הוחמץ. רענן את הדף (F5) לאחר כמה שניות.
לחצתי "הרץ שרשרת" וקיבלתי "ניתוח עדכני". מה עושים?
שער הטריות (freshness gate) חוסם ריצה חוזרת פחות מ-14 ימים מהניתוח האחרון. אם רוצים לרוץ בכל זאת, לחץ על הקישור "הפעל בכל זאת" שמופיע בהודעה.
GitHub Pages לא מציג כלום, כתובת לא נמצאת.
יש להפעיל Pages ידנית פעם אחת: github.com/rotemstainai23/portfolio ‹ Settings ‹ Pages ‹ Deploy from branch ‹ main / (root) ‹ Save. לאחר כ-3 דקות הכתובת תהיה פעילה.
אין מחירים ב-heatmap במצב ענן, כל הריבועים אפורים.
מחירים חיים זמינים רק במצב Live. במצב ענן, ה-heatmap מציג נתוני הדוח היומי האחרון שנדחף ל-repo. אם הדוח ישן יותר מיום, ייתכן שה-Actions לא רץ. בדוק ב-github.com/rotemstainai23/portfolio/actions.
האפליקציה לא נשמרת כ-PWA ב-Chrome ב-iPhone.
ב-iOS, Chrome ו-Firefox לא תומכים בהתקנת PWA. חייב להשתמש ב-Safari ולבחור "הוסף למסך הבית" מכפתור השיתוף.
האם מישהו יכול לראות את האחזקות שלי?
ה-repo הוא ציבורי. כל מי שיש לו את הקישור יכול לראות את הנתונים. אם תרצה פרטיות מלאה, ניתן לעבור ל-repo פרטי (GitHub Pro, כ-4 דולר לחודש), ה-Pages עובד גם עם repo פרטי.
