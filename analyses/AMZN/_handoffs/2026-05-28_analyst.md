## ג.6 תרחיש דובי — מוכר בחסר

**הטיעון החזק ביותר נגד הקנייה:**
1. **FCF Trap:** $200B CapEx FY2026 = FCF שלילי לכל 2026. שווי שוק $2.92T על FCF שלילי.
2. **Valuation premium בלי FCF support:** P/E 31.7x על EPS מנופח ב-Anthropic. Clean EPS → P/E ~38x.
3. **Azure structural edge:** Microsoft 365 bundle = ש-Azure מגיע "בחינם" עם Office. AWS צריך להתחרות על כל עסקה.
4. **Historical parallel — FY2022:** אמזון בנתה יכולת לוגיסטית עצומה בCOVID, ירד לרווח $12.2B ו-FCF שלילי -$16.9B. CapEx AWS יכול להיות Over-build המקביל ל-2022.
5. **AI spending plateau risk:** אם hyperscaler capex cycle "peaks" ב-2026 — AWS overcapacity, לחץ תמחור, ירידת margin.

**מה יכול לפגוע קבוע:**
- Azure enterprise lock-in מעמיק, OpenAI migration away from AWS
- רגולציה: FTC antitrust split-up (AWS + Amazon retail נפרדים)
- AI native startups שמייתרים פלטפורמת AWS (model-as-a-service)

**אי-ידועים:**
1. AWS margin trajectory כש-CapEx depreciation מואץ
2. Anthropic valuation שיקוף בדוחות עתידיים
3. Amazon Leo / Kuiper revenue timeline
4. מה "OpenAI $100B" מייצג — כמה הוא incremental vs. existing spend
